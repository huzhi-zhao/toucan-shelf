## 2. 收藏阅读

写作时看到值得以后再读的文档，标一下收藏；闲下来时从手机书架翻出来读。

- **在哪里标**：两端都能标、都能取消（2026-10-18 改：原先只在 web 端）。
  - web：文档编辑页右上角菜单里的"收藏 / 取消收藏"。
  - 手机：阅读页右上角菜单里的"收藏 / 取消收藏"。
- **只能手动移走**：程序判断不了是不是真的读完了，所以读完也不会自动移出，由用户自己取消收藏。不做"已读"状态。
- **在哪里看**：手机书架页加一块"收藏"，像阅读列表：
  - 每行显示文档标题和所在知识库，点开进阅读页；
  - 先列钉住的，再列最近收藏的 5 篇（按收藏时间，最新的在前）；钉住的不占这 5 篇的名额；
  - 最后一个"全部"入口，进去是完整的收藏列表，同样钉住的在前、其余按收藏时间。
- **钉住**：有些收藏时间久了但很重要，钉住后一直显示在书架上。在收藏列表里钉住、取消钉住。
- **个人的**：每个用户只看到自己的收藏。文档自带的"置顶"（`pinned`，从 memos 继承）是所有人共用的，
  不拿来当收藏；收藏单独存一张表（用户、文档、收藏时间、是否钉住）。
- 文档被删除或者没有权限读了，就不在列表里显示。
- 待定：收藏块放在书架顶部"最近阅读"的下面、知识库上面，还是放到知识库下面。

## 3. 知识库待办预览

知识库文档里的 `- [ ]` 现在只能一篇篇打开看，想在手机上一眼看到"知识库里还挂着哪些事"。

- **和计划的待办是两回事**（2026-10-18 定）：不搬进计划，不互相同步，也不做"加入计划"。
  原先考虑的几种做法（只读汇总、整批转成计划待办、约定推送）都先不做，先按下面这样上线看效果。
- **每天定时整理**：每天定时把所有知识库里没做完的 todo 整理出来，生成一份清单。
- **app 里只预览**：清单列在 app 里，每条能跳到对应的文档；勾掉、看前因后果都去文档里做。
- 已知条件：文档已经记录"是否有没勾的任务"（`has_incomplete_tasks`），文档列表接口可以按它筛选，
  不用全量扫描；calendar 块里的 `[ ]` 写在代码块中，不算任务。
- 待定：
  - "整理"是程序按规则抽取（每条 `- [ ]` 原样列出，按知识库、文档分组），还是由 agent（AI）读过之后归纳、去重、排序。
  - 清单存在哪：一篇固定的文档，还是一张单独的表。
  - 入口放在哪：搜索页（搜索历史改成点进搜索框才弹出）、计划页，还是书架。
  - 跳过去以后能不能在手机上直接勾选。手机阅读页现在是只读的，要能勾就得加写入，还要处理和 web 端同时编辑的冲突。
  - 哪几种标记算"没做完"（`[ ]` 之外的 `[>]` 等）。

## 4. 整理现有的视图和布局，评估手机端支持哪些

现状（2026-10-18）：

| 类型 | 是什么 | 手机端现在 |
|---|---|---|
| Markdown 文档 | 普通文档 | 正常渲染 |
| HTML 文档 | 整页 HTML | 正常渲染 |
| PDF 文档 | PDF 附件 | 交给 Safari 自带的阅读器打开 |
| VIEW 文档 · 相册（Gallery） | 按范围实时列出子文档的卡片墙 | 占位卡片 |
| VIEW 文档 · 日历布局 | 按日期属性把文档铺到月历上 | 占位卡片 |
| VIEW 文档 · 说明文本 | 视图里的一段 Markdown | 随视图一起占位 |
| `calendar` 代码块 | 打卡日历（已由计划取代） | 占位卡片 |
| `kanban` 代码块 | 看板 | 占位卡片 |
| `grid` 代码块 | 卡片网格 | 占位卡片 |
| `mermaid` 代码块 | 流程图等 | 正常渲染 |
| draw.io 图 | 带源码的 SVG 图片 | 按图片显示 |
| 加密块（`toucan-secret`） | 加密内容 | 占位卡片 |

- 要做的四种，按这个顺序：相册 > 日历布局 > 看板、卡片网格（只读简化版）。都只读，用来浏览。
- calendar 块已经有计划替代，优先级最低；加密块暂不在手机上解密。
- `sheets` 表格已经彻底下线，以后也不会再启用，不在评估范围内。
- 这条和二期候选里的"常用视图只读预览"（[mobile-reader.md](mobile-reader.md) §11 第 2 条）合并考虑。

## 5. "我的"页面自定义

- **设置收进右上角**：现有的设置项（账号、字号、深色模式、添加到主屏幕、退出登录）收进右上角按钮，
  "我的"这一页留给自定义项目。计划设置不放进来，留在计划页。
- **自定义项目**在设置里配置，每项包括：图标、标题、备注、关联的 Markdown 文档。
  例：💰 · 年度理财计划 · "配置 7.7w，risk 5000，2026 年底到期" · 关联理财计划文档。点开进关联文档。
- **排序**：在设置里拖动排序。
- **渲染样式**可选，三期至少支持：多行条状（标题一行、备注另起一行）和单行条状（标题和备注同一行）。
- 待定：项目存在服务器上（跟账号走，换设备也在）还是只存本机；能不能分组；
  备注里的数字要不要以后从关联文档自动取。

## 6. 不做的

- **web 端兼容计划功能**：永远不做（2026-10-18 定）。电脑上也直接用手机端，宽屏下居中限宽显示。
- **知识库加星、书架只显示加星的知识库**：讨论过，不做。书架照旧显示全部知识库，
  只是把封面改小成一行 3 个（2026-10-17 已改）。
