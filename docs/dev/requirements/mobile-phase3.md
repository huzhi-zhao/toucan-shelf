## 2. 收藏阅读

写作时看到值得以后再读的文档，标一下收藏；手机上闲下来时从书架翻出来读。

- **在哪里标**：只在 web 端，文档编辑页右上角的菜单里加"收藏 / 取消收藏"。手机端不标。
- **在哪里看**：手机书架页，知识库下面加一块"收藏"，像阅读列表：
  - 按收藏时间排，最新的在最前；
  - 每行显示文档标题和所在知识库，点开进阅读页。
- **不会自动移走**：收藏一般不是长期的，但读完不自动移出，由用户自己手动取消收藏。
- **个人的**：每个用户只看到自己的收藏。文档自带的"置顶"（`pinned`，从 memos 继承）是所有人共用的，
  不拿来当收藏；收藏单独存一张表（用户、文档、收藏时间）。
- 文档被删除或者没有权限读了，就不在列表里显示。
- 待定：
  - 手机阅读页上能不能直接取消收藏（读完顺手移走）。
  - 收藏很多时，书架上只显示前几篇、再给一个"全部"入口，还是全部列出。

## 3. 浏览知识库里的待办

知识库文档里的 `- [ ]` 也是待办，现在只能一篇篇打开看。想在手机上一眼看到"知识库里还挂着哪些事"。

- **搜索页改版**：搜索历史只在点进搜索框时才弹出；平时搜索框下面显示知识库待办，按知识库分组。
- 三种做法，待定：
  - **A. 只读汇总**：从各知识库文档里收集没勾的 `- [ ]`，按知识库分组列出，点一条进到那篇文档。
    数据仍只在文档里，不会两头不一致。
  - **B. 转成计划的待办**：把知识库待办搬进计划。会出现两份，改了一边另一边不知道，不推荐整批转。
  - **C. 约定推送**：在知识库里定近期能执行的事时，主动推送一条到计划的待办，用"关联文档"指回原文。
  - 倾向 **A + C**：平时用 A 浏览；某条要排进近期计划时，在 A 的列表上点"加入计划"，
    建一条关联了原文档的计划待办。
- 已知条件：文档已经记录"是否有没勾的任务"（`has_incomplete_tasks`），文档列表接口可以按它筛选，
  不用全量扫描；calendar 块里的 `[ ]` 写在代码块中，不算任务。
- 待定：具体是哪几种标记算"没做完"（`[ ]` 之外的 `[>]` 等）；手机上能不能直接勾掉（现在阅读页是只读的）；
  一个知识库里待办很多时怎么折叠。

## 4. 整理现有的视图和布局，评估手机端支持哪些

先出一份清单，再逐个判断手机上要不要支持、做成什么样。现状（2026-10-18）：

| 类型 | 是什么 | 手机端现在 |
|---|---|---|
| Markdown 文档 | 普通文档 | 正常渲染 |
| HTML 文档 | 整页 HTML | 正常渲染 |
| PDF 文档 | PDF 附件 | 交给 Safari 自带的阅读器打开 |
| VIEW 文档 · 相册（Gallery） | 按范围实时列出子文档的卡片墙 | 占位卡片 |
| VIEW 文档 · 日历布局 | 按日期属性把文档铺到月历上 | 占位卡片 |
| VIEW 文档 · 说明文本 | 视图里的一段 Markdown | 随视图一起占位 |
| `calendar` 代码块 | 打卡日历（已由计划取代） | 占位卡片 |
| `kanban` 代码块 | 看板 | 占位卡片 |
| `grid` 代码块 | 卡片网格 | 占位卡片 |
| `sheets` 代码块 | 可编辑表格 | 不在占位名单里，会按 web 组件渲染，手机上的效果待核实 |
| `mermaid` 代码块 | 流程图等 | 正常渲染 |
| draw.io 图 | 带源码的 SVG 图片 | 按图片显示 |
| 加密块（`toucan-secret`） | 加密内容 | 占位卡片 |

- 初步倾向：相册和日历布局最值得做（浏览用，只读）；看板、卡片网格可以先做成只读的简化版；
  calendar 块已经有计划替代，优先级最低；加密块暂不在手机上解密。
- 这条和二期候选里的"常用视图只读预览"（[mobile-reader.md](mobile-reader.md) §11 第 2 条）合并考虑。

## 5. "我的"页面自定义

- 现有的设置项收到右上角按钮里，"我的"这一页留给自定义项目。
- **自定义项目**在设置里配置，每项包括：图标、标题、备注、关联的 Markdown 文档。
  例：💰 · 年度理财计划 · "配置 7.7w，risk 5000，2026 年底到期" · 关联理财计划文档。点开进关联文档。
- **渲染样式**可选，三期至少支持：多行条状（标题一行、备注另起一行）和单行条状（标题和备注同一行）。
- 待定：项目存在服务器上（跟账号走，换设备也在）还是只存本机；能不能排序、分组；
  备注里的数字要不要以后从关联文档自动取。

## 6. 不做的

- **web 端兼容计划功能**：永远不做（2026-10-18 定）。电脑上也直接用手机端，宽屏下居中限宽显示。
- **知识库加星、书架只显示加星的知识库**：讨论过，不做。书架照旧显示全部知识库，
  只是把封面改小成一行 3 个（2026-10-17 已改）。
