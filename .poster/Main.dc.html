ToucanShelf
SELF-HOSTED KNOWLEDGE BASE

Everything
you know,
and everything
you keep.

A hierarchical knowledge base with Notion-style views, AI-native collaboration, and a place for the files you already have.

Single Go binary SQLite · no CGO MIT
github.com/huzhi-zhao/toucan-shelf
A respectful fork of usememos/memos
01
Hierarchical Knowledge Base
Workspaces, multi-level folder paths and a visual Bookshelf — Yuque's depth without its weight. Read and edit from any browser; there is no desktop app to install or sync.
02
Attachments & Storage
S3-compatible object storage with per-workspace prefixes, served through the app — never a bare presigned URL.
PLANNED NAS resource roots — index the files already on your disks. Never re-upload them.
03
Gallery Views
Notion-style card walls scoped by folder, tag or property. A view document holds configuration only — it always reflects current data, never a stale snapshot.
04
View Blocks
calendar · kanban · grid · sheets — interactive fenced blocks with write-back gestures straight from the preview.
05
AI Agent Collaboration
memogit checks a base out to plain files; MCP reaches it over HTTP with nothing on disk. Both snapshot a human baseline first.
06
Hybrid RAG Search
FTS5 keyword retrieval and vector similarity, fused and re-ranked — with a keyword fallback that covers every document type.
07
Publish & Share
Send a document to your own public site: themes, a navigation tree, sitemap and canonical URLs — and a real 410 when you withdraw it.
